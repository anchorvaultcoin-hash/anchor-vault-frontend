# AnchorVaultCoin

**Non-custodial crypto vault for ERC-20 assets on Ethereum Mainnet.**

AnchorVaultCoin adds an additional security layer for storing and managing crypto assets.

## Status

* **Network:** Ethereum Mainnet
* **Security audit:** Hexens — completed, 0 Critical / 0 High
* **Contract source:** verified on Etherscan
* **Product:** Mainnet release
* **Vault dashboard:** `pulse.html`

## Supported assets

AnchorVaultCoin supports multiple ERC-20 assets, including:

**ANCR, WETH, USDC, USDT, WBTC, DAI, UNI, AAVE, stETH, wstETH, rETH, RPL, USDe, LINK**

The supported asset list may expand over time.
